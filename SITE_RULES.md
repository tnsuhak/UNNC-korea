# UNNC Korea site-specific operating notes

These notes are durable site-specific decisions for future edits.

- Verify factual claims with authoritative/official sources, but **do not add a user-visible `자료 출처` / source box or a small source-links section by default**. Add visible source links only when the user explicitly requests them or when they are essential for a specific content type such as news.
- Keep official-source verification in the editorial/research process rather than adding source clutter to ordinary UNNC guide pages.
- All UNNC detail pages should reuse the **same standard consultation panel** already used across the site. Do not invent a page-specific consultation CTA design unless explicitly requested.
- When editing a detail page, preserve the shared consultation panel and footer unless the requested change specifically concerns them.

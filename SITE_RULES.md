# UNNC Korea site-specific operating notes

These notes are durable site-specific decisions for future edits.

- Verify factual claims with authoritative/official sources internally, but **do not add a user-visible `자료 출처` / source box or a small source-links section by default**. Add visible source links only when the user explicitly requests them or when they are essential for a specific content type such as news.
- Write ordinary UNNC guide pages as a direct local-language information site. State verified facts directly instead of using reporter/research wording such as `~에 따르면`, `공식 자료 기준`, `브로셔에 따르면`, `학교 자료를 보면`, or similar source-attribution phrasing.
- Keep official-source verification in the editorial/research process rather than adding source clutter to ordinary UNNC guide pages.
- News articles are the main exception: preserve the original source and source link when editorially required.
- All UNNC detail pages should reuse the **same standard consultation panel** already used across the site. Do not invent a page-specific consultation CTA design unless explicitly requested.
- When editing a detail page, preserve the shared consultation panel and footer unless the requested change specifically concerns them.
